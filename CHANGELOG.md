# Changelog

All notable changes to GutSporePredict will be documented in this file.

## [4.0.0-beta1] - 2026-08-01

### Added

- End-to-end command line interface (`gutsporepredict run`)
- Automatic Prodigal protein prediction
- HMMER-based gene detection
- Competitive HMM assignment
- Module evaluation framework
- Developmental stage prediction (ST001–ST009)
- Lifecycle prediction engine
- YAML-based biological knowledge system
- Command logging
- Comprehensive unit tests
- Strict type checking with mypy
- Ruff formatting and linting
- Public command-line interface

### Changed

- Modular pipeline architecture
- Improved prediction reproducibility
- Automatic resource discovery

### Fixed

- CLI argument validation
- Type annotations
- Competitive assignment edge cases
